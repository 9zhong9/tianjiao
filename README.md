# 宿舍日记：脚边的信任

一个无需构建工具的 AI 对话与好感度系统前端原型。当前版本使用本地规则模拟角色回复，方便私人测试 UI、角色切换、对话和存档。

## 运行

直接用浏览器打开 `index.html` 即可。进度保存在浏览器的 `localStorage` 中。

## 功能

- 7 名成年虚构大学室友角色
- 每名角色独立对话记录、好感度和信任度
- 体贴/尊重边界的对话会提升关系数值
- 越界关键词触发拒绝和关系下降分支
- 暂停互动、结束对话和重置进度
- 明确规定：睡眠、昏迷或无法表达意愿时不发生接触

## 接入真实 AI

在 `app.js` 的 `sendMessage` 中替换本地回复逻辑即可。生产或联网版本应通过后端调用模型，不要在前端暴露 API 密钥，并在后端保留同意、年龄、内容安全和举报处理逻辑。

本原型只实现非露骨、基于明确同意的互动，不提供绕过模型或平台安全规则的功能。
